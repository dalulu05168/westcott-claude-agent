# 交稿前剧情审查

按当次请求判定适用项。优先检查会改变课堂任务或可交付性的具体问题。

涉及写法、成长任务或人物互动时，查 [编剧样本索引](../../../reference/writing-samples/index.md)，只读与当前问题相关的样本。给出贴合本场的修法。稿件优先满足用户实际要求，过审可以采用不同的情节和节奏。像样本里的旧行情、角色经验和后续预告等内容，只按本场已验证素材判断。

| 检查 | 需修改的情形 |
|---|---|
| 承接 | 误用其他课的进度，把待解问题当成已学，或让人物提前知道尚未出现的信息。 |
| 课堂推进 | 只在最后提一句成长任务，正文没有讲清它与眼前知识的关系。需要改时指出哪段讲解、问题或答复可以接住它。 |
| 角色互动 | 相邻成员机械复述上一句的关键词、换词重复同一个判断或重复提问。词面承接只有在增加观察、条件、异议或新问题时才通过。 |
| 后续边界 | 下午任何角色提前给出晚课核心判断、用反问预设结论、代讲师总结，或多条发言合起来推完关键证据链。也检查尚未确定的课题是否被写成承诺。 |
| 证据与身份 | 未核实数字写成事实，模拟成员或交易被写成真实记录，或把图表信号写成对机构交易的身份证明。 |
| 交付范围 | 短段落被扩成整晚，新内容改动了用户要求保留的部分，或该交的正文被内部分析替代。 |

接受来自成员提问、David 顺势讲解、案例和练习等多种推进方式。能从正文指出具体来回才算完成成长任务。若正文已经满足目标，直接通过。审稿结果交总导演处理。独立审稿结果不代表用户已采用稿件。

稿件带成员编号时，按导演提供的旧版人员表核对编号、性别、称呼和候选范围。历史原文可保留其编号，写新稿时核对当场是否有授权使用留档人员。有成员活动时检查问话归属及当场已知信息。旧课提出的疑问由原成员承接，或让其他成员明确接话。按场景判断语气和出场是否自然。

按 [发言规范](../../../reference/speech-format.md) 检查整块交付。财经新闻首段写清国家与事件，第二段有事实，第三段同时涵盖关键影响和具体关注点，下面一行配图直链应对应该事件。David 两段需要有明确的判断、证据边界和可跟随的解释。指出拆开发送、段落顺序错误、证据不足和空泛影响。正文用角色标记与空行表达结构。

按 [三场分工](../../../reference/operations.md#三场角色与分工) 查实际出场及用户明确安排的例外。资讯助理负责开闭群，David 默认晚间出场，Gabriela 默认群稿外收答。检查闭群三句话及最后发言角色、等材料停点、助理是否泄露答案或积分，以及周二、周四晚间有无布置课后任务。带编号的新编互动须有教学模拟标识。

审下午稿先读导演提供的晚课待答问题、结论及推理边界。单看末句仍是提问时，也回看整场是否已经透出答案。逐对核对相邻成员发言各自新增了什么，单纯机械复述和提前剧透都判「需修改」，引用触发的原句或连续几句。复审要用最终改过的段落及相邻发言再查一次。

按 [中文发言口吻](../../../reference/whatsapp-voice.md) 逐人检查。所有新台词及审稿结论用简体中文，成员句子短并接具体话题，表情随人随场景。检查中式聊天套路、复制式表态、过度表情和行话。角色判断须符合已确认的组别及跨场学习进度，避免新人始终只提基础问题。对生硬台词指出原句并给自然中文替换句。

按 [新闻与场次规则](../../../reference/news-broadcast-policy.md) 审核核查员给出的原始发布时间和实际排稿顺序。普通新闻必须为罗马尼亚当地当天，只有上午允许美股上一交易日指标与美国前夜重大新闻。对照白天已发新闻检查跨场倒序。按 [统一配置](../../../reference/scene-rules.json) 查完整场发言总条数。按 [运营记录](../../../reference/operations.md) 和当日确认材料核对推票、活动、课程与停点。
