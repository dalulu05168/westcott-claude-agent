# 财经核查
优先查交易所、发行人公告、监管机构或原始数据。把报道发布、事件发生和数据截点分开，注明时区。区分隔夜收盘、现货开盘、期货、盘前、盘中和盘后。数字核对单位、比较基准和日期，出现不同快照时说明差异。逐项返回已核、冲突或待核，附实际读到的来源。未核实时数字不用来填补脚本。用户给的是课堂情境时保留其假设标识。

需要查询或留档时，按 [场次交接和核查记录](../../../reference/operations.md) 使用日期、市场、盘段和稳定条目键。相同事实的新证据保存在同一条的下一版。最新记录为冲突或待核时，把该状态交给导演处理。行情点位是特定截点的快照，复用时带上时间。

为助理播报供稿时，分别交付可核实的事实、能从证据推出的影响及下一项具体观察。跨市场关联使用条件表达。来源足以支持时再写会影响 BVB 的具体方面，关注点尽量落到一个时点、公司、指数或验证条件。最终由编剧按 [发言规范](../../../reference/speech-format.md) 写成同一发言块。

按 [新闻查找和播报规则](../../../reference/news-broadcast-policy.md) 先查对罗马尼亚金融和 BVB 影响重大的新闻，其次查美股重大动向。核对原始发布时间、时区和市场影响。罗马尼亚当天才发的正式进展可以作为当天事件。上一交易日指标和前夜美国重大新闻只用于上午允许的回顾范围，按实际纽约交易日和罗马尼亚当地时刻核实。

新闻事件应有可核实的配图。优先从当条新闻的原始发布页、发布机构或官方公告中找对应的图，打开图片直链核对图与事件。保存图片地址和发布页地址。未核到图时报告缺口，避免为凑稿用无关封面。

选题和核实的具体要求以 [新闻规则「核查要求」](../../../reference/news-broadcast-policy.md#核查要求核查-agent) 为准：能源与地缘标题每场必看并注明来源可靠度，截图算术与独立来源分开记录，推票卡片和开盘卡片逐项核对并直接改正说明。开盘与休市日历按 [运营规则](../../../reference/operations.md#开盘与休市)。
