# 助理与先生发言规范

每条发言的角色标记独占一行，正文紧接下一行。相邻发言之间直接换行，零空行。新闻或讲解在同一条正文内需要分段时依原格式留空行。聊天最终交付用同一个 `text` 代码块包裹本次完整剧本，第一行直接写角色标记。

新编编号对话的教学模拟说明放在聊天代码块外。成员按确认的编号和性别使用原有标记。含有同行台词或姓名的历史发言按原文读取。工作人员的公开标签和三场出场范围按 [运营分工](operations.md#三场角色与分工)。

## 开群与资讯助理的口吻

完整场由资讯助理开群。上午、下午、晚上每场（含周日）第一句固定为「🌤 大家早上好！欢迎回到 ELLERY WESTCOTT 社群！」，按时段换「早上／下午／晚上」，「社群」前不加其他词。首句之后空一行，只用一两句说今天的看点（例如「又到周五了。昨晚美股跌得很重……今天我们先回顾美股收盘，再看看欧洲和罗马尼亚今天的消息😊」），不在开群这条里塞指数和数字。然后先让两三位成员问候，再单独发下一条。范本见 [金牌样稿库 G03](gold-samples.md)。

助理像群里的资讯助理在说话，不像在交核查报告。直接说话，不加自造的小标题，不写「经核实」「核查显示」「数据截至××:××」「以下为本场资讯」这类报告腔。称呼群里的人用「大家」「各位」或「成员」，不说「学员」「同学」。助理偶尔简短回应成员的问题（一两句，讲清就停），不是每次开口都只发新闻。

播报节奏：
- 新闻按原始发布时间从早到晚播，不往回跳。临近美股开盘不播 BVB 行情，日间不单独发「开盘前速览／期货速览」。
- 盘中不写具体时刻，用「今天上午」「盘中」「开盘后不久」，保留「盘中仍会变化」的意思；固定节点预告不在此列。未收盘不说「收绿／收红」，说「见绿／飘红」。
- 延时、等截图、等核对、几点开没开这类写作安排不进正文。
- 活动开场只写题目、回答方式和交给顾问 Gabriela，不写积分。活动提醒要轻松、每天换说法，不像命令。

闭群三句（仅当次范围包含闭群时）：感谢参与 → 下一场会继续关注什么、欢迎回来 → 祝福和再见。不罗列刚聊过的事件，不给下一场活动卖关子；措辞每天换，结构不变。晚课后第二句换成当晚课程要点。上午办过竞猜时，上午闭群和下午开群各轻松带一句「把预选答案发给顾问 Gabriela」。

## 群稿的固定播报顺序（上午、下午）

1. **开群**：固定首句 + 一两句今天看点。之后 2–3 位成员简短问候（「早」「早上好，又到周五了！」）。
2. **美股回顾（上午）**：单独一条，标题一行「🇺🇸 美股｜前一交易日收盘回顾」，空一行后写日期（周几）、三大指数方向（直接说「全线大跌／普遍上涨」）、各自收盘点位和涨跌幅，再加一两只当天焦点个股。不写「对罗马尼亚市场来说」，不写「接下来」。
3. **每条新闻**：按下节三段式。新闻之间按原始发布时间排序。
4. **每条播报后的成员**：2–4 位各说一句，长短不一。至少一句是从刚播的数字里看出的问题或反差（「ANT涨了17%，纳指还是跌了2%😅」「拨备多，是因为贷款多了，还是坏账多了？」），可以有一句只表达感受或接一个本地关切。成员不替别人解释公司是做什么的、券商能不能买、交易时间几点；这类信息如必须交代，由助理一句带过。
5. **助理补充**：只在成员问到具体事实且后面讨论需要时，用一句回答，不重复刚播过的内容。

## 资讯助理的财经新闻

使用固定标记「===== 资讯助理 =====」。写得短、突出重点，不堆解释、不凑字数。每条新闻的正文有三段：

1. 一行国旗、国家和短主题。美股消息写「🇺🇸 美国财经新闻｜短主题」，罗马尼亚消息写「🇷🇴 罗马尼亚财经新闻｜短主题」，欧洲及其他国际消息写「🌍 国际财经新闻｜短主题」。标题后空一行。
2. 只写核心事实和关键数字（用「约／附近」即可）。开头用自然的来源引述，例如「据美国媒体今日报道」「据今日公布的财报」「根据BVB今日公告」「据今日美股盘前报道」，不必每条列一长串媒体名，也不强写「罗马尼亚媒体」冒充来源。关键事实要写全，例如债券上市写规模、票面利率、付息频率、到期时间；前一天有同类事件可以顺带一句。
3. 一两句点出对罗马尼亚市场或相关代码的影响，以「接下来，我们重点关注……」或「接下来可以关注……」收尾。开头不必每次都用「对罗马尼亚市场来说」，也可以用「值得关注的是」「对投资者来说」。

每条正文下方另加独立的「配图：」和已核事件图片直链。暂时找不到已核事件图时，新闻照常写，配图行写「配图：待补」，并在代码块外列出待补图片的新闻标题和建议来源；不因缺图删掉新闻。配图和正文一次交付，仍算一条发言。全员用中文，口吻见 [中文发言口吻](whatsapp-voice.md)。

下例是用户认可的范文。配图一行是位置示意，正式出稿要填已打开核查的事件图片直链。

~~~text
===== 资讯助理 =====
🇺🇸 美国财经新闻｜美伊关系释放缓和信号，国际油价回落

据美国媒体今日报道，特朗普表示，目前再次对伊朗发动大规模打击的可能性较低，并计划与卡塔尔首相会面。受此影响，国际油价明显回落，布伦特原油一度跌至94美元附近，WTI跌至87美元附近。

对罗马尼亚市场来说，油价变化值得关注，尤其是OMV Petrom（SNP）和Romgaz（SNG）。接下来，我们重点关注美伊谈判进展、国际油价走势，以及明天美国CPI公布后对市场的影响。

配图：<已核实的事件配图直链>
~~~

用户 2026-11-17 认可的第二篇范文（罗马尼亚消息，换了第三段开头）：

> 🇷🇴 罗马尼亚财经新闻｜Avant Credit首期债券登陆BVB
> 根据BVB今日公告，罗马尼亚金融机构Avant Credit的首期公司债券正式上市，规模约180万欧元，票面年利率11%，每半年付息一次，2029年5月到期。公司主要为企业提供融资服务，隶属于捷克APS Holding集团。

## David 先生的发言

使用固定标记「===== David先生 =====」。每次发言的正文有两段：

1. 回应当前疑问，先把判断、依据和证据的边界讲清楚。
2. 解释背后的逻辑，并给出具体的观察或验证方法。用词稳妥，因果清楚，结论以能够说明的证据为限。遇到确认过的机构教学主线时，在讲解中按课序推进。

晚课里成员翻出白天的原话来问时，David 先接住那句话里的一个具体细节，再顺着讲当课的核心观点。「跟着先生学」的形象靠一次次讲清判断步骤、让成员能自己用上来建立：给原则、误区和「下节课继续看什么」，不自夸、不暗示盈利、不安排成员集体夸他。

以下是用户提供的格式示例。

~~~text
===== David先生 =====
这正是需要分清楚的地方。放量说明交易活跃，但图表不会直接告诉我们是哪家机构在买、哪家机构在卖。

所以，学习技术形态有两个目的：第一，通过价格和成交量，观察机构等大资金可能留下的交易痕迹，理解它们可能的操作方式；第二，结合后续走势验证这些线索，寻找更合理的交易时机，而不是看到上涨就盲目跟进。
~~~

上面这段讲到机构视角，只适合课程路线中后期；阶段一、二照格式写，不照搬机构这层理念，见 [理念递进](evening/teaching-method.md#理念递进)。

## 使用格式检查

把要交付的正文传给 `validate_speech_format`。独立新闻选 `news`，独立先生发言选 `teacher`，新写群聊选 `mixed`，同时传 `session`、布加勒斯特 `date` 及 `scope`。整场用 `full`；中段和待核停点按实际交付范围传 `excerpt` 或 `partial`。有明确闭群或等待要求时传 `close: required` 或 `close: forbidden`。用户明确安排特殊出场时，才在格式和条数校验传 `allowed_staff`（`teacher` 或 `adviser`）。David 在上午和下午场一律 0 条，传了 `allowed_staff: ['teacher']` 也判不通过；他只在晚间授课和周日 19:30 复盘出场。

用户点名修改 51–65 的旧条目时，两个校验都传 `scope: partial` 及 `allowed_member_ids` 中的具体编号。

最终出稿设置 `strict_layout: true`，传入聊天代码块内的纯文本，围栏留在聊天输出层。

工具检查限定角色、标记、段数、标题、空行及新闻配图。传入顺序检查返回的 `expected_news`，逐条比对国家、标题及已核直链。闭群语义、证据和自然度由核查与审稿判断。历史原文按用户要求保持原样，编辑时只校验本轮改写范围。
