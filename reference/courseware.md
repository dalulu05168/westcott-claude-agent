# 课件与标准形态图（课件 Agent 用）

来源：旧版 `westcott-efficient-workflow` 2.3.2 的晚间 `courseware.md`、`part-05.md`，2026-11-19 并入。生成工具用法见 [课件生成说明](lesson-kit.md)。与 [CLAUDE.md](../CLAUDE.md) 冲突时以 CLAUDE.md 为准。

## 先分清两种图

- **标准教学图**：模拟数据，只服务形态教学，图上注明「教学模拟示意，非真实行情」，不附会具体股票和日期。
- **实际案例图**：真实行情，记下代码、市场、日期、观察截止时点、K 线周期和来源；只在总导演的单课方案里写明「采用」时才做。

## 图组

每种形态按知识重点选 4–6 张，单图只讲一个重点：

| 图号 | 阶段 |
| --- | --- |
| 图01 | 形成前 |
| 图02 | 结构初现 |
| 图03 | 关键位出现 |
| 图04 | 确认触发 |
| 图05 | 常见误判 |
| 图06 | 失效或反例 |

- 同一图组复用相同基础走势，后一张只增加新出现的 K 线、条件或分支，不提前显示未来结果。形成中的图不画确认结果；失败图指明哪个条件没成立。
- 每根 K 线：高点不低于开盘和收盘，低点不高于开盘和收盘；成交量非负，标注与所指 K 线一致。只用可控绘图工具（`build_lesson_kit`）生成，不用生成式绘图随机拼 K 线或文字。
- 课上只问到某根时，从那根起用 `chart.hypothetical_from` 标为假设区。
- 命名：`课程编号_形态名称_图序_阶段.png`，图号、讲稿引用和图片文件建立对应表。

## 尺寸、颜色和文字

- 3840×2160、16:9、无损 PNG，原生高清，不拉伸。交付前核实际像素。
- 绿涨红跌，按收盘对开盘判定；平开平收用灰色并在图例说明。建议色值：上涨 `#168A55`，下跌 `#D64545`，对应量柱 `#A6D8BE`／`#EAB1B1`，关键位与颈线橙色虚线 `#E58B2A`，辅助线 `#577A9E`，高亮浅底 `#F6F1E7`／`#F1F3F5`，正文 `#252525`。现有工具的绿色为 `#15825c`、红色为 `#be3a4a`，与建议色值略有不同，同一组课程内保持一致即可。
- 文字：主标题 72–88 像素，主要标注 44–56 像素，坐标和辅助说明不小于 36 像素。标注用引线或留白区，与实体、影线、量柱错开。确认、待确认、失效除了颜色还要有文字或线型区别。图标题、课件标题和先生口头说法用同一套词（颈线、确认、失效）。

## 左上角 Logo

正式 Logo：[westcott-logo-original.png](assets/westcott-logo-original.png)（1448×1086，透明底，元数据和校验值见 [logo-metadata.json](assets/logo-metadata.json)）。不重绘、不改色、不裁切、不变形。

- 3840×2160 画布上宽 384–499 像素，系列默认约 442 像素，高度按原比例；左边和上边安全边距 96 像素。
- 不遮挡图标题、K 线、坐标轴、成交量、关键标注、颈线和边界线。冲突时先挪标题和图表区，再在宽度范围内调 Logo。
- 同一组课程参数固定，要改就整组一起改。
- 现有 `build_lesson_kit` 还不会自动放 Logo。正式图需要 Logo 时，交付里写明「Logo 待放置」，不称品牌成品已验收。

## 课件文档

- `build_lesson_kit` 每次调用产出一套：浏览器课件 `lesson.html`、一张 SVG 形态图、讲师提纲和学员练习，见 [课件生成说明](lesson-kit.md)。
- **图组**：工具一次只出一张图。4–6 张图组靠多次调用生成，每张图一次调用、复用同一组基础 K 线并逐张追加；图号表里写明每个图号对应的生成目录。
- **PNG 与命名**：工具只直接输出 SVG。3840×2160 PNG 由用户在 `lesson.html` 里点「下载 4K 图」导出，按「课程编号_形态名称_图序_阶段.png」改名；课件 Agent 不能导出或核对像素，交付时把这一步写进待办，并标「像素待核」。
- **理念课没有练习**：工具要求必须填 `exercise`。周二、四理念课填「本课无课后练习（不发群）」作占位，交付时说明 `exercise.md` 不发群。
- 用户要 Word 课件时，按旧版规范交付：全文宋体（正文小四、1.5 倍行距，一级标题三号加粗、二级标题四号加粗）；依次放课程信息、目标与承接、问题引导、案例说明（如有）、形态讲解、例子辨析、理念总结、互动设计、下节承接，不适用的注明原因；图片按原比例嵌入，图号、图题、简短说明紧挨图片。生成后渲染检查缺字、分页、溢出、变形和缩小后难辨的标注；无法渲染时写「页面视觉待核」。

## 交付给总导演

实际生成的文件、图号对应表、每张图的制作状态（已出图／方案／待核），以及本次没完成的项。只有方案时明说是方案。缺外部数据时照样做模拟图，不伪造市场案例。周二、四理念课不出课后练习。
