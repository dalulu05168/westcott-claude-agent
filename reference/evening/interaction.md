# 课堂互动设计（编剧用）

来源：旧版 `westcott-efficient-workflow` 2.3.2 的晚间 `interaction.md`、`part-04.md`（4.6–4.7）、白天 `writer.md` 多人对话检查、`writing-examples.md` 语义检查，2026-11-19 并入。成员怎么说话以 [成员口吻与出场](../member-cast.md) 为准，本文件只管互动怎么设计。与 [CLAUDE.md](../../CLAUDE.md) 冲突时以 CLAUDE.md 为准。

## 先找真实难点

按总导演给的讲稿、前情和角色资料设计互动。先找本课真正的难点（例如「触及颈线算不算突破」），再决定谁在哪个讲解点开口。出场人数和发言条数没有要求时按教学需要安排，不默认全员出场，不固定同几个人轮换。

## 六种作用

每条成员发言只承担一个主要作用，紧跟具体讲解内容。不必每课集齐，也不为轮换人物补造个人经历。

表里的例子只示范作用和口吻，写台词时按本场的图、数字和前情重写，不原样搬用。

| 作用 | 说什么 | 例子（教学模拟） |
| --- | --- | --- |
| 疑惑 | 普通人的直接困惑 | 「碰到颈线就算确认了吗？」 |
| 误解 | 学习阶段合理会出现的错 | 「量一放大就是突破了吧。」 |
| 追问 | 紧扣图号或条件追问一个概念 | 「图三那根要是收在线下呢？」 |
| 连接 | 把白天市场或别人的原话接到课上 | 「Mihai上午不是问过，SNP派完息还算不算便宜吗？」 |
| 反思 | 承认自己以前常这么做 | 「我以前看到反弹就以为见底了😅」 |
| 承接 | 帮先生过渡到下一层 | 「那要是等不到确认，是不是就不做？」 |

这六种之外，质疑、反问、不服、拿定存和国债来比照样可以出现，比例不必低于配合教学的发言。先生讲完没人较真，反而不像这个群。

## 设计边界

- 误解要合理且能被本课纠正，不编极端错误。先生先指出具体差异，再给判断依据，不只说「你理解错了」，不靠权威压下质疑。
- 允许有人简短回应、保留意见、说还没明白，或干脆不出声。
- 持仓写成不带个人事实的问法（「要是手里有SNP，这种时候该看什么？」），或留【持仓】占位；不写「我买了」「我赚了」。
- 不组织集体夸奖先生，不让成员替机构作证或诱导跟单。「跟着先生学」靠一次次讲清判断步骤建立，一场里赞同先生的句子最多一两句。
- 模拟发言不能用来证明真实成员已经信任团队或掌握课程。
- 教学模拟标识写在代码块外，块内只放台词（CLAUDE.md 交付排版）。

## 多人对话自检

- 多人围绕同一主题时，每句提供不同关注点；一个疑问换词重复的，删掉一句或改成补新观察、限定条件、提出异议。
- 不让所有人排队提问，也不让每个人完整复述课程结论。
- 先生是否真的回答了成员的疑问？人物有没有说出还没公布的信息？
- 去模板只修重复作用的句子，不把全稿改成统一短句。

## 交付形式

- **只要设计时**：给「插入位置—作用—模拟台词—先生回应要点」表，表头注明教学模拟预案。
- **要正文时**：输出完整台词片段，功能表不进正文。
- 局部修改只改指定部分，不另加收尾和作业。

## 语义检查（交稿前）

1. 意义：立场、条件、不确定性、时间与比较对象变了没有？
2. 范围：交的是指定部分吗？有没有多加课程、行动或结尾？
3. 连续性：上一段发生的事有来源吗？人物能否知道尚未公布的信息？
4. 表达：是否重复同一作用，或为了区分人物虚构口癖和经历？
5. 事实：模拟、引用、推断和实际记录分开了吗？数字一致不等于事实已核实。

局部改写时逐项比较原句与新句的主体、行动、时间、条件、否定、不确定性、数量和证据状态，尤其留意「可能→确定」「观察→买入」「计划→完成」「曾买入→已卖出」。只修具体问题，最多两轮。
