# 从已采用的课稿生成课件

使用 `read_record` 读取目标定稿。按正文选学习目标、讲解顺序和练习。需要合成图时，使用能准确体现课程所讲结构的价格和成交量示例，并保留教学模拟标识。

## `build_lesson_kit` 输入

- `adopted_id` 是这堂课已经采用的编号。若只有草稿，等用户明确采用后再生成正式课件。
- `learning_goal` 写本课学员练习的判断动作。`lecturer_points` 按讲解顺序写。`exercise.prompt` 仅放学员题目，讲师参考答案可填 `exercise.answer`。
- `chart.title` 概括形态或观察点，`chart.level` 可填示意的关键价位。每根 K 线提供 `open`、`high`、`low`、`close` 和 `volume`。所有数值用于教学演练。
- `chart.hypothetical_from` 填第一根假设 K 线的位置，从 1 开始数。例如第四根跌破，课堂只问第五根能否站回时填 5。第五根及以后显示为浅黄假设区。讲稿、图例和学生题目要使用相同的真假边界。

## 输出

文件保存在项目的 `.westcott-state/lesson-kits/` 中。相同的定稿和相同的课件内容会复用已有文件。调整输入可生成另一版。

| 文件 | 用法 |
| --- | --- |
| `lesson.html` | 浏览器课件。可翻页或按左右方向键，能打印为 PDF。点「下载 4K 图」保存 3840×2160 PNG。 |
| `lesson-chart.svg` | 单独的矢量形态图。使用绿涨、红跌、灰平盘。 |
| `teacher-notes.md` | 讲师提纲、练习参考、课堂承接和定稿编号。 |
| `exercise.md` | 学员练习，便于复制到群里。 |

## 验收

用独立测试目录的已采用回踩课生成课件。确认第四根跌破，只有第五根起显示为假设。打开课件，翻到练习页，检查题目与图一致，再下载 PNG 检查尺寸。讲师参考答案留在讲师提纲里。
